# My Saku 💰

> A simple and modern personal finance tracker for managing daily pocket money and expenses.

My Saku is a lightweight personal finance web app designed to help users track their daily balance, record expenses, and understand their spending habits through simple charts and transaction history.

The project is built as a single HTML file with embedded CSS and JavaScript, making it easy to run without a backend or complicated setup.

## ✨ Features

- 💰 **Daily Balance**
  - Track today's income and expenses
  - Automatically calculate the remaining balance

- ➕ **Pocket Money Tracking**
  - Quickly add daily pocket money
  - Automatically record it as an income transaction

- 💸 **Expense Tracking**
  - Add expenses with descriptions
  - Organize expenses into categories:
    - Food
    - Drinks
    - Transportation
    - Snacks
    - Entertainment
    - Others

- 📋 **Transaction History**
  - View today's income and expenses
  - Clear transaction history when needed

- 📊 **Spending Charts**
  - Expense distribution by category
  - 7-day spending trend
  - Category breakdown

- 🌙 **Dark & Light Mode**
  - Switch between dark and light themes

- 🔄 **Automatic Daily Reset**
  - Automatically start a new daily balance
  - Preserve previous spending data for the 7-day chart

- 📤 **CSV Export**
  - Export transaction history as a CSV file

- 💾 **Local Storage**
  - Data is stored locally in the browser
  - No backend or database is required

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- [Chart.js](https://www.chartjs.org/)
- [Phosphor Icons](https://phosphoricons.com/)
- Browser Local Storage
